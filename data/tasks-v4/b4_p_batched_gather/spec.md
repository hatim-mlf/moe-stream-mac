Implement `batched_gather_rows(x, indices)`. Convert x to an array and indices to an array. Require x rank 3 `(batch, rows, features)`, indices a 2-D integer array of shape `(batch, take)` (bool is not integer here), and all indices in `[0, rows)`; otherwise raise ValueError. Return an independent copy of shape `(batch,take,features)` preserving x dtype. Empty batches/take/features are valid.
