Define `ByteRing` as `{ uint8_t *data; size_t capacity, head, size; }`. `void byte_ring_init(ByteRing *q, uint8_t *storage, size_t capacity)` initializes an empty ring at head 0. `int byte_ring_write(ByteRing *q,const uint8_t *src,size_t n)` appends all n bytes or returns -1 without mutation if invalid/full. `int byte_ring_read(ByteRing *q,uint8_t *dst,size_t n)` removes exactly n oldest bytes or returns -1 without mutation if invalid/empty. Return 0 on success. `q` must be nonnull; capacity must be positive and storage nonnull; `src`/`dst` may be null only for n=0. Buffers do not overlap ring storage. State must satisfy head<capacity and size<=capacity. No allocation.
