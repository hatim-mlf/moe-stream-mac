Implement `uint8_t float_to_e4m3fn(float x)` for finite x using the finite-only E4M3 format. Bit 7 is sign; exponent bias is 7; exponent 0 uses subnormals `mantissa*2^-9`; exponents 1..15 use `(1+mantissa/8)*2^(exponent-7)`, except code 0x7f is NaN and unavailable. Return the nearest representable finite value, ties to the code with an even least-significant bit, and saturate magnitudes above 448 to 448. Preserve negative zero. Input is finite. No allocation.
