Implement `void max_pool2x2_f32(const float *x,size_t rows,size_t cols,float *out)`. Input is row-major. Output has shape `(rows/2, cols/2)` using integer floor division; each output is the maximum of its corresponding nonoverlapping 2 by 2 block. Drop incomplete bottom/right edges. If either output dimension is zero, access no pointers. Otherwise pointers are valid and buffers do not overlap. No allocation.
