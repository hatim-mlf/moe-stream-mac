Implement `int hex_encode_lower(const uint8_t *src,size_t n,char *dst,size_t cap)`. Write exactly two lowercase hex digits per byte, followed by `\0`; return the character count. Require `cap >= 2*n+1`; return -1 for null `dst`, null `src` when n>0, insufficient capacity, or a result not representable as int. For n=0, `src` may be null and write an empty string. On failure do not modify dst. No allocation.
