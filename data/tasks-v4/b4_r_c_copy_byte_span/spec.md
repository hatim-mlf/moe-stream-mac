Implement `int copy_byte_span(const uint8_t *src,size_t src_len,size_t offset,uint8_t *dst,size_t dst_cap,size_t count)`. Copy `src[offset:offset+count]` to dst. Arbitrary overlap between source and destination is allowed. Return 0 on success or -1 for invalid pointers, an out-of-range source slice, or insufficient destination capacity. Check bounds without overflowing; on failure leave dst unchanged. Zero count permits null pointers.
