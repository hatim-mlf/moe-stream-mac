Implement `int layer_norm_affine_f32(const float *x,const float *scale,const float *bias,size_t n,float eps,float *out)`. Require n>0, finite positive eps, nonnull pointers, and finite elements in all three input arrays. Compute the population mean and variance of x in double; write `((x[i]-mean)/sqrt(variance+eps))*scale[i]+bias[i]` as float. On invalid input return -1 without writing out; otherwise return 0. Inputs and output are disjoint. No allocation.
