Implement `pack_ragged(rows)`. `rows` is an iterable of 1-D numeric arrays. Return `(flat, offsets)`, where `flat` concatenates values and `offsets` is int64 of length `len(rows)+1`, starts at zero, and records each row end. Use the result type of all row dtypes. For no rows return float64 empty `flat` and offsets `[0]`. Raise ValueError for non-1-D or nonnumeric rows; do not mutate rows.
