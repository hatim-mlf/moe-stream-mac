Implement `int q16_16_divide_sat(int32_t numerator, int32_t denominator, int32_t *out)`. Treat operands and result as signed Q16.16. Compute `(numerator * 65536) / denominator`, round to nearest with ties to even, then saturate to int32 range. Require nonnull output and nonzero denominator; on invalid input return -1 without changing output. Use a wide intermediate and no allocation.
