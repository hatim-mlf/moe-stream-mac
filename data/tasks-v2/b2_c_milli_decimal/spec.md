Implement `int parse_milli_i64(const char *text, int64_t *out)`, parsing a signed decimal amount into thousandths. Grammar: optional `+` or `-`, one or more integer digits, optionally `.` followed by 1 to 3 digits. No whitespace or other bytes. Missing integer digits, a bare decimal point, or more than 3 fractional digits is invalid. Right-pad the fraction to 3 digits. Reject values outside int64 range. Return 0/-1 and preserve output on failure.
