Implement `scatter_add_rows(base, indices, updates)`. Convert `base` and `updates` to float64; require a 2-D base, 1-D integer indices (an empty Python list is valid), and updates with shape `(len(indices), base.shape[1])`. Indices must be in range and all values finite, otherwise raise ValueError. Return a new float64 copy of base with updates added in input order; duplicate indices accumulate. Inputs are not mutated.
