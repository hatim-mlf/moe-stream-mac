Define `Packet` as `{ uint16_t tag; uint8_t size; uint8_t bytes[4]; }` and `PacketQueue` as two fixed arrays of four packets plus `size_t in_count, out_count`. Implement `void packet_queue_init(PacketQueue *q)`, `int packet_queue_push(PacketQueue *q, const Packet *p)`, and `int packet_queue_pop(PacketQueue *q, Packet *out)`. Push/pop return 0 on success, -1 for null arguments, full/empty queue, or a pushed size above 4. Failure must not mutate queue or output. FIFO order; no allocation. Packet arguments do not alias queue storage.
