Implement `int parse_i16_csv(const char *text,int16_t *out,size_t cap,size_t *count)`. Parse a nonempty comma-separated list of canonical signed decimal int16 values: optional `+`/`-`, digits, no leading zeros except `0`, no spaces. Return item count, or -1 for invalid input, range/capacity errors, or null required pointers. On failure change neither output array nor `*count`; `out` storage does not overlap `text`. No allocation.
