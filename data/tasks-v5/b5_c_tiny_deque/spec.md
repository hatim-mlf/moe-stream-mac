Define `TinyDeque` as `{ int32_t data[8]; size_t head, size; }`. Implement `void tiny_deque_init(TinyDeque*)`, `int tiny_deque_push_front(TinyDeque*, int32_t)`, `int tiny_deque_push_back(TinyDeque*, int32_t)`, `int tiny_deque_pop_front(TinyDeque*, int32_t*)`, and `int tiny_deque_pop_back(TinyDeque*, int32_t*)`. Operations return 0 on success and -1 on null arguments, full push, or empty pop. A failed operation changes neither deque nor output. Storage is fixed; no allocation.
