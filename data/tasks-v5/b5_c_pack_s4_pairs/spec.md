Implement `int pack_s4_pairs(const int8_t *values, size_t n, uint8_t *dst, size_t cap)`. Encode each signed value in [-8,7] as its low four two's-complement bits. Even indices occupy the low nibble; odd indices occupy the high nibble. An unused final high nibble is zero. Return bytes written, or -1 for invalid pointers, a value out of range, insufficient capacity, or a byte count above INT_MAX. For n=0 return 0 and allow null pointers. On failure leave dst unchanged. No allocation.
