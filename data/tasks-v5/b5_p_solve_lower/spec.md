Implement `solve_lower_triangular(matrix, rhs)`. Convert both to finite float64 arrays. Matrix must be square, rhs 1-D of matching length, every entry above the diagonal must be zero, and every diagonal entry nonzero; otherwise raise ValueError. Return a float64 solution to `matrix @ x = rhs` by forward substitution. Empty 0-by-0 input with empty rhs is valid. Do not mutate inputs.
