Implement `int parse_route_slot(const char *text, char *name, size_t cap, uint16_t *slot)`. Accept exactly a lowercase ASCII route name matching `[a-z][a-z0-9_]*`, `@`, then canonical decimal 0..65535 (no leading zeros except `0`). Return 0 on success; otherwise -1 for invalid text, null pointers, or insufficient name capacity. On failure leave both outputs unchanged. The output buffers do not overlap.
