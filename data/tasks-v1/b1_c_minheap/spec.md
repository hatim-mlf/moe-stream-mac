Implement a fixed-capacity min-priority queue with no allocation. Define SmallMinHeap { int data[16]; size_t len; }. Provide void minheap_init(SmallMinHeap *q), int minheap_push(SmallMinHeap *q,int value), and int minheap_pop(SmallMinHeap *q,int *out). Init sets len to zero. Push returns 0 or -1 when q is null/full. Pop returns 0 and removes the minimum, or -1 for null/empty arguments; failures do not mutate the queue or output. Equal values are allowed.
